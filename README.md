CLUBE DO FOCINHO

Projeto web desenvolvido para o Clube do Focinho, uma organização dedicada à proteção, ao cuidado e ao bem-estar animal.

A aplicação foi construída utilizando conceitos modernos de desenvolvimento front-end, oferecendo uma experiência de navegação dinâmica por meio da arquitetura Single Page Application (SPA). O sistema permite a apresentação dos projetos da organização, divulgação de suas ações e o cadastro de pessoas interessadas em participar das atividades e campanhas promovidas.

OBJETIVO

Desenvolver uma aplicação web organizada, responsiva, acessível e de fácil manutenção, aplicando conceitos fundamentais do desenvolvimento web moderno.

O projeto contempla:

- Estruturação semântica com HTML5
- Estilização responsiva com CSS3
- Manipulação dinâmica do DOM com JavaScript ES6+
- Arquitetura SPA com carregamento dinâmico de conteúdo
- Validação de formulários
- Acessibilidade e boas práticas de usabilidade
- Otimização de imagens utilizando o formato WebP
- Controle de versão com Git e GitHub
- Processo de build e empacotamento utilizando Vite

TECNOLOGIAS UTILIZADAS

- HTML5
- CSS3
- JavaScript ES6+
- Vite
- esbuild
- Git
- GitHub

FUNCIONALIDADES

- Navegação sem recarregamento da página
- Exibição dinâmica dos projetos da organização
- Formulário de cadastro com validações
- Tema claro e escuro
- Persistência das preferências do usuário
- Layout responsivo para diferentes dispositivos
- Menu adaptado para dispositivos móveis
- Recursos de acessibilidade e navegação por teclado

RESPONSIVIDADE

A aplicação foi desenvolvida utilizando Flexbox, CSS Grid e Media Queries para garantir adaptação adequada em diferentes resoluções de tela, proporcionando uma experiência consistente em computadores, tablets e smartphones.

ACESSIBILIDADE

Foram adotadas boas práticas de acessibilidade, incluindo:

- Uso de elementos semânticos
- Atributos ARIA
- Navegação por teclado
- Estrutura lógica de conteúdo
- Contraste adequado entre elementos visuais

PROCESSO DE BUILD

O projeto utiliza o Vite como ferramenta de desenvolvimento e empacotamento. Durante o processo de build, os arquivos são minificados pelo esbuild, reduzindo o tamanho dos recursos e contribuindo para um melhor desempenho da aplicação.

COMO EXECUTAR O PROJETO

Instalar as dependências:

npm install

Executar em ambiente de desenvolvimento:

npm run dev

Gerar a versão de produção:

npm run build

Visualizar o build localmente:

npm run preview
